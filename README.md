## 🌟 Why This Repo

This repository is meant to make replication work in digital markets more accessible by providing a centralized collection of datasets and code.

It is especially useful for:

- researchers studying digital economics  
- students working on the digital economy and industrial organization  
- instructors building replication-based coursework
